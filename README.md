# Marketplace Landing Page

A modern, responsive marketplace landing page built with **HTML, CSS, and Vanilla JavaScript**. The project features a clean glassmorphism UI, dark/light mode, live product search, responsive layouts, and interactive components without requiring any external frameworks.

## ✨ Features

- Modern Glassmorphism UI
- Fully Responsive Design
- Light & Dark Theme Toggle
- Live Product Search
- Dynamic Product & Category Rendering
- Smooth Scroll Navigation
- Scroll-to-Top Button
- Newsletter Subscription Form
- Pure HTML, CSS & JavaScript
- No Build Tools Required

## 📁 Project Structure

```
/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 Getting Started

1. Clone or download this repository.

```bash
git clone https://github.com/yourusername/marketplace-landing-page.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

Or simply upload the files to any static hosting service.

## 🌐 Deployment

This project can be deployed on any static hosting provider, including:

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages
- Firebase Hosting
- Traditional cPanel Hosting

No server-side configuration is required.
